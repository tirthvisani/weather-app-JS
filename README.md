# Weather App 🌦️

A simple weather application that shows real-time weather data using an API.

## 🚀 Features
- Search weather by city
- Shows temperature, humidity & conditions
- Responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeather API
